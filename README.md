# Deforestation Detection using Machine Learning

## Overview
Deforestation Detection using Machine Learning is an intelligent environmental monitoring system developed using Python. The project analyzes forest satellite images to detect deforestation, estimate tree loss, identify affected forest regions, and generate environmental status reports.

The system allows users to upload forest images, enter forest name, simulate forest changes, detect deforested regions using image processing, and generate detailed analytical reports. It also supports CSV export and email alert notifications to forest departments for environmental action.

---

## Features

### Forest Image Upload
Users can upload forest or satellite images for analysis.

### Forest Name Input
Users manually enter the forest name for identification.

### Image Simulation & Detection
The system simulates the forest image and highlights deforested regions in blue for easy visualization.

### Deforestation Analysis
Generates:
- Forest Name  
- Tree Loss Count  
- Tree Loss Percentage  
- Deforestation Percentage  
- Forest Status  

### CSV Report Export
Results can be exported in CSV format for reporting and analysis.

### Email Alert System
Sends automated email notifications with deforestation report to forest departments for action.

## Workflow
1. Upload forest image  
2. Enter forest name  
3. Simulate image  
4. Detect deforested areas  
5. Calculate tree loss & percentage  
6. Generate report  
7. Export CSV / Send email alert
